Chronicare
Chronicare is a comprehensive mobile application designed to help individuals living with chronic conditions take control of their health. Whether you’re managing diabetes, hypertension, asthma, or any other long-term illness, Chronicare offers personalized tools and features to support daily health tracking, medication adherence, appointment reminders, and doctor-patient communication.

Key features include:
  • Health Data Tracking – Monitor vital signs like blood pressure, sugar levels, and symptoms daily.
  • Medication Reminders – Get timely alerts to ensure consistent medication adherence.
  • Appointment Scheduling – Set and receive reminders for upcoming medical visits.
  • Doctor-Patient Messaging – Communicate securely with healthcare providers in real-time.
  • Educational Resources – Access articles and tips tailored to your condition.
  • Progress Reports – Visualize health trends and share reports with your doctor.
  • User-Friendly Interface – Simple, intuitive design for all age groups and tech skill levels.
  • Real-Time Notifications – Stay informed about your treatment plan and next steps.
With an intuitive interface and real-time notifications, Chronicare empowers users to proactively manage their chronic conditions and stay connected with their care team.

Oasis
Oasis is a modern web application designed to streamline the process of renting, booking, and managing residential properties. Built with a seamless user experience in mind, Oasis connects property owners with tenants through a secure, scalable platform that supports real-time interactions, personalized listings, and recommendations based on location and previous likings.

Key features include:
  • User Authentication - with tokens for secure access and personalized experiences.

  • Property Listings - with dynamic filtering, image galleries, and detailed descriptions.

  • Booking & Leasing System - allowing users to reserve properties and manage active leases.

  • Reviews and Ratings - to help users make informed decisions.

  • Admin Dashboard - for property managers to track bookings, reviews, and user activity.

  • API-First Architecture - powered by Flask and MySQL for fast and scalable backend operations.

  • Responsive Frontend - built with React (or vanilla JS/HTML/CSS) for cross-device compatibility.

Whether you're a landlord looking to showcase your properties or a tenant in search of a reliable home, Oasis offers the tools you need.

Farm Guard
FarmGuard is an intelligent agricultural monitoring system designed to help aquaculture farmers detect and respond to predator threats in real time. Combining computer vision, machine learning, and hardware integration, FarmGuard enhances farm security by identifying predators and triggering automated acoustic deterrent actions.

Key features include:
  • Real-Time Threat Detection - using camera input and machine learning models to identify predators.
  • Automated Response System - that activates connected devices, e.g., acoustics when threats are detected.
  • Hardware Device Integration - with Arduino or Raspberry Pi for low-power, offline deployment in remote farms.
  • Mobile Notifications - alert farmers instantly when unusual activity is detected.
  • Customizable Detection Models - for different farm environments and threats.
  • Data Logging & Analysis - to help improve future threat response and prevention.
